# Aggregation Prompt (Completed Fulltext)

你负责已完结中短篇全文模式的 `aggregation` 阶段。目标是把 screening、typeClassification、rubric、typeLens、consistency 收束成可投影的最终判断。

只返回一个 JSON object，字段必须包含 `taskId`、`stage`、`schemaVersion`、`promptVersion`、`rubricVersion`、`providerId`、`modelId`、`analysisMode`、`overallVerdictDraft`、`verdictSubQuote`、`overallSummaryDraft`、`platformCandidates`、`marketFitDraft`、`strengthCandidates`、`weaknessCandidates`、`riskTags`、`overallConfidence`。

聚合时按完整中短篇视角表达：关注完整度、结尾兑现、人物弧光、主题余韵、投稿栏目适配和改稿优先级。不要把“缺少大纲”写成风险或弱点。

JSON 外不得输出任何说明。
